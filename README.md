# DeFi Portfolio Tracker

Легковесный облачный веб-трекер DeFi-портфеля. Портфель — три фиксированные категории (**BTC / ETH / Stablecoins**): количество BTC и ETH читается из залога на Aave v3 по адресам кошельков (read-only) плюс ручные корректировки, проинвестированные стейблы вносятся подписанными записями. Одна компактная таблица показывает количество, стоимость, цену, долю, цель, отклонение и **сколько монет купить/продать** для выравнивания.

Учет портфеля ведется **независимо от долгов** — заемные средства и health factor живут в отдельном контуре.

Статус: **Фаза 1 в разработке.**

## Ключевые принципы

- **Три фиксированные категории**: BTC, ETH, Stablecoins. Никаких произвольных корзин.
- **Портфель независим от долга**: заемные средства не вычитаются из категорий и не влияют на проценты.
- **Только чтение**: никаких приватных ключей, сид-фраз и подписи транзакций — никогда.
- **Бюджет**: внешние данные — бесплатные тиры (Alchemy, CoinGecko Demo, Supabase Free); платный только хостинг (Vercel Pro $20/мес — мониторингу health factor нужен cron раз в 15 минут, а Hobby даёт один запуск в сутки). Лимит $50/мес не превышается.
- **Пошаговая поставка**: каждая фаза самостоятельно выкатываема и полезна.

## Локальная разработка

```bash
npx supabase start && npm run seed:admin && npm run dev
```

Вход только по паролю администратора из `ADMIN_EMAIL` / `ADMIN_PASSWORD` — публичной регистрации нет, остальных пользователей админ создает в разделе «Настройки».
