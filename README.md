# DeFi Portfolio Tracker

Легковесный облачный веб-трекер DeFi-портфеля: чтение балансов и позиций по адресам кошельков (read-only), целевые пропорции и отклонения, средняя цена покупки по ручному леджеру сделок, снепшоты, лендинг (Aave v3) и размещение заемных средств (GMX v2, Uniswap v3).

## Ключевые принципы

- **Только чтение**: никаких приватных ключей, сид-фраз и подписи транзакций — никогда.
- **Бюджет**: вся инфраструктура на бесплатных тирах (Alchemy, CoinGecko Demo, Zerion free, Vercel Hobby, Supabase Free); лимит $50/мес не тратится.
- **Гросс-учет долга**: аллокация от суммы активов, долг отдельной строкой, net worth в шапке.
- **Пошаговая поставка**: каждая фаза самостоятельно выкатываема и полезна.
